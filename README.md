# Next.js Sample Project

This is a simple test project built with **Next.js**.  
It is used for practicing Next.js fundamentals, components, and routing.

## 🛠️ Tech Stack
- Next.js
- React
- TypeScript
- Styled Components
- State Management Library

## ⚙️ Notes
- The APIs used in this project are only available locally, so the features, including authentication may not work if you clone the repo.
